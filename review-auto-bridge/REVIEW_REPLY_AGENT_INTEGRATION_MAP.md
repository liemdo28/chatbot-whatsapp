## Integration Points

### Point 1: GBP Review Scraping → Agent Pipeline

**From:** `auto-reply.js` (main bridge) fetches real reviews via `scraper.js` → `scrapeAllReviews()`

**To:** `review-agent/pipeline.js` → `run()`

**Hook location:** In `auto-reply.js`, inside the `update()` callback after reviews are fetched:

```javascript
// In auto-reply.js — after new reviews are added to store.reviews
// Wire this AFTER the scrape + dedup + classification:

const { run } = require('./review-agent/pipeline');

async function processWithAgent(review) {
    const result = await run({
        store_id: review.location_id || 'bakudan_rim',
        platform: review.platform || 'google',
        rating: review.rating,
        review_text: review.review_text,
        reviewer_name: review.reviewer_name,
        review_id: review.id,
    });
    return result;
}
```

**Recommended:** Call `processWithAgent()` in `auto-reply.js` after reviews are fetched. If `result.requires_approval` is true, push to `store.approval_queue` (already done by pipeline). If `result.auto_reply_allowed` is true and `dry_run=false`, call `postReplyToGBP()` to post live.

### Point 2: Approval Queue → WhatsApp Notification

**From:** `review-agent/audit.js` → `saveApproval()` creates entries in `review_reply_approvals.json`

**To:** `whatsapp-ai-gateway/` notification system

**Approval message format** (already generated by `pipeline.js`):
```
New Review Reply Needs Approval
Store: bakudan_rim
Platform: google
Rating: 3 stars
Reviewer: John
Review: "Food was good but the ramen came out late..."

Detected issues:
- wait_time
- service

Suggested reply:
"Hi John, thanks for being honest with us..."

Reply:
1 = Approve
2 = Edit
3 = Reject
4 = Escalate
```

**Integration:** Send this `approval_message` string to WhatsApp via existing WhatsApp notification function in `whatsapp-ai-gateway/`.

**Webhook trigger:** After `POST /api/reviews/reply-agent/run` where `requires_approval === true`, call WhatsApp function with `approval_message`.

---

### Point 3: Manager Decision → Reply Posting

**From:** `whatsapp-ai-gateway/` or CEO dashboard

**To:** `POST http://localhost:8788/api/reviews/approvals/:id/decide`

**Payload:**
```json
{
  "decision": "approve",
  "decided_by": "manager",
  "edited_reply": null
}
```

**Decision options:** `approve` | `reject` | `edit` | `escalate`

After decision `approve`, the final reply should be posted to Google via `scraper.js` → `postReplyToGBP(gbp_review_id, approved_reply)`.

---

### Point 4: Existing review-auto-bridge Approval Queue

**From:** `review-agent/audit.js` → `review_reply_approvals.json`

**To:** `review-auto-bridge/data/store.json` → `approval_queue`

Both stores exist. Recommendation: deprecate the old `store.approval_queue` and migrate to the new `review_reply_approvals.json` system. The old `approval.html` dashboard at port 8787 can continue to read from `review_reply_approvals.json` via a new API bridge route.
